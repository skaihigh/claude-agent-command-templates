@pwa-specialist

Perform a comprehensive PWA audit:

1. **Service Worker Status**
   - Check if service worker is registered
   - Review caching strategies
   - Verify cache versioning

2. **Offline Functionality**
   - Test offline mode support
   - Check IndexedDB schema
   - Verify data persistence

3. **Performance**
   - Analyze bundle sizes
   - Check cache hit rates
   - Review loading performance

4. **PWA Manifest**
   - Verify manifest.json configuration
   - Check icons and theme colors
   - Review app metadata

5. **Recommendations**
   - Suggest improvements
   - Identify potential issues
   - Provide optimization tips

Run Lighthouse PWA audit if possible and provide actionable recommendations.
